This Website

▶

That's right, the first project is this website! I call this a project not neccesarily due to the website itself, but due to setting up the domain. I managed to get a free domain from DigitalPlat, but the reason it was free is because it's not the .com or .net domain extensions you're used to. (called TLDs, top-level domain) The domain extension is .qd.je. (called SLDs, second-level domains) After I had acquired the domain, (wazan.qd.je) it was time to find somewhere to host the website, because remember, DigitalPlat only gave me the domain, nothing else. Luckily, I remembered I had a test website on GitHub Pages, a website hoster. Now, the hard part comes in. I had to find a way to link GitHub Pages to the domain I had registered. (DNS, for the technical folks) For this I used FreeDNS, a website made in 2001 to handle DNS records. After hooking everything up, the website kind of just sat there for a while until I decided to do something with it and create this website.

Tech: HTML, CSS, JS
Year: 2026
Link: DigitalPlat, FreeDNS, GitHub Repo (the one behind this website)

The Greatest OS Of All Time

▶

I built an OS from the ground up, no Linux base, not even FreeBSD. The OS can currently:

  1. Access the web (limited, although it works)
  2. Play a very run down version of DOOM
  3. Save files between reboots (persistent storage)

And it also has a fully working file explorer and terminal! (and a not-so-good file editor) No github repo yet though. (Also to run it you have to use this quite specific command: qemu-system-i386 -cdrom falastinos.iso -m 32 -machine pc -nodefaults -vga std -drive file=falastinos.qcow2,format=qcow2,index=0,media=disk -netdev user,id=net0,hostfwd=tcp::5555-:23 -device e1000,netdev=net0)

Tech: C, Assembly
Year: 2026
Link: ISO File Download
